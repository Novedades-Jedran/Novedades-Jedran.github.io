# Novedades Jedran

Página web responsive para Novedades Jedran.

## Archivos

- `index.html` — estructura de la página.
- `styles.css` — diseño y adaptación responsive.
- `script.js` — menú móvil, filtros de categorías y catálogo.
- `assets/logo-jedran.jpeg` — logo de Novedades Jedran.
- `assets/promocional-jedran.jpeg` — imagen promocional.

## Publicar en GitHub Pages

1. Sube todos los archivos respetando la carpeta `assets`.
2. Asegúrate de que `index.html` esté en la raíz del repositorio.
3. En GitHub entra a **Settings → Pages**.
4. Selecciona la rama que contiene el proyecto y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub Pages publique el sitio.

## Cambiar productos

Edita el arreglo `products` dentro de `script.js`.

Cada producto tiene:
- `name`
- `category`
- `price`
- `icon`

Más adelante se pueden reemplazar los emojis por fotografías reales de cada producto.
